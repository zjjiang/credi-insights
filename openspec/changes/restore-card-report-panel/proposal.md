# Proposal: 恢复卡片账单周期报告与分类面板

## 问题

多卡架构重构（commit `72c9a96`）把首页从"账单列表"（`UploadBatchCard` 组件流）换成了"卡片网格"。旧首页上挂着三个常用功能，因为承载它们的 `UploadBatchCard` 组件不再被任何页面引用，变成孤儿代码：

- 月度消费 PDF 报告下载
- AI 重新分类（对某期账单的交易重新跑分类规则）
- 未分类交易的商户分组处理 + 本期 Top10 大额交易

对应的后端接口（`GET /api/uploads/[id]/report`、`POST /api/uploads/[id]/reclassify`、`GET /api/uploads/[id]/transactions`）都还在正常工作，只是没有 UI 入口可以触发。用户依赖这三个功能日常核对账单，目前完全不可用。

`multi-card-architecture` 的 `upload-card-linking` spec 当时已经设计了"卡片详情页显示历史账单列表"（`GET /api/cards/[cardId]/uploads`），但相关任务从未实现，是这次补齐这几个功能所缺的那块拼图。

## 目标

在卡片详情页 `/cards/[id]` 补齐"按账单周期查看"的入口：
- 新增账单周期选择下拉（数据源：该卡的历史 `Upload` 记录，按账期倒序）
- 选中某期账单后可下载该期 PDF 报告、触发重新分类
- 选中账单下有未分类交易处理（商户分组、批量指定分类）和 Top10 大额交易两个 tab

## 用户体验

1. 打开某张卡片的详情页，"本月概览"卡片下方新增"账单周期"区块
2. 下拉选择某一期账单（显示账期 `账期起~账期止`，缺失时兜底显示 `imageMonth` 或文件名）
3. 选中后出现「下载报告」「重新分类」两个按钮，以及「明细 / 未分类 (N) / 大额」三个 tab
4. 若该卡尚无任何账单，账单周期区块不显示

## 非目标

- 不做按自然日历月筛选的通用月份选择器（那是本月概览卡片之外的另一个更大缺口，本次不处理）
- 不恢复旧首页的账单列表视图，不修改 `UploadBatchCard.tsx` 本身
- 不涉及 MCP 服务里 Rule pattern 字段与网页规则字段语义不一致的问题（另一个已知问题，不在本次范围）

## 约束

- 三个功能均为迁移复用已验证过的实现逻辑，不重新设计交互或计算逻辑
- 复用现有 API（报告、重新分类、按上传取交易），只新增一个"按卡片取账单列表"接口
